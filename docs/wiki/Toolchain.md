# Toolchain

- Godot 4.7.2 .NET (mono) editor for Linux x86_64, plus the matching export templates.
- .NET SDK 8.
- Android: SDK with build tools, JDK 17, gradle build (needed by the OpenXR vendors plugin).
- Quest: USB `adb`, frame timing from `adb logcat -s VrApi`.
- Native libraries: ZenKit and dmusic for linux-x64 and android-arm64 from [binary-dependencies](https://github.com/Gothic-Unity-Project/binary-dependencies).

Details follow as the spike sets them up.
